## 1. Mục tiêu

1. Toolchain JDK 25 + Maven hoạt động (đã cấu hình JAVA_HOME/PATH).
2. Cấu trúc Maven đa module tại `implementation/` (parent + `dhopm-common`).
3. Seed `dhopm-common`: io (reader FIMI/text), config (`MiningConfig`), contract (`Engine`/`Pattern`/`MineResult`), **TestKit TC1–TC8**, util chung (log scaffold).
4. **Validate 7 dataset** trong `dataset/` (FIMI reader + tái sinh bảng thống kê 5.2 qua test tự động).
5. `mvn test` xanh trên JDK 25.
